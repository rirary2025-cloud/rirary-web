# Skill: Rirary Quality Check

## Pre-completion checklist

### Functional
- All navigation links resolve
- Buttons/CTAs lead to expected destinations
- Contact paths work
- No broken image references

### Responsive
Check at minimum:
- 375px
- 768px
- 1024px
- 1440px

### Accessibility
- Keyboard navigation
- Visible focus states
- Labels for form controls
- Logical heading order
- Adequate contrast
- Reduced-motion support

### Technical
- `npm run lint`
- `npm run build`
- No obvious hydration warnings
- Avoid unnecessary client-side JavaScript
- Images use `next/image` when appropriate

### Visual
- No arbitrary spacing drift
- Section widths align
- Typography hierarchy remains consistent
- CTA treatment is consistent
