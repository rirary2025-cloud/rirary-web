# Skill: Rirary SEO

## Required basics
- Unique title and description per indexable route
- Canonical URL strategy
- Open Graph metadata
- Twitter/X card metadata where useful
- `sitemap.ts`
- `robots.ts`
- Semantic heading order
- Descriptive alt text for meaningful images
- Internal links between services, works, regional projects, and contact

## Structured data direction
Use schema.org where appropriate:
- Organization
- LocalBusiness only if business details satisfy the schema
- Article for news/blog content
- BreadcrumbList on detail pages

## Content SEO
Write for actual user intent first. Avoid keyword stuffing.
Create service detail pages that answer:
- What the service solves
- Who it is for
- What Rirary does
- Expected process
- Related works
- Contact CTA
