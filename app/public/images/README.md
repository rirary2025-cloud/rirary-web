# Photo asset slots

Preferred production files:

- `hero-main.webp` — landscape 1600px+; actual Rirary / Hokkaido field activity
- `hero-sub.webp` — portrait or square 1000px+; people / collaboration scene
- `regional-main.webp` — landscape 1600px+; regional project activity
- `about-main.webp` — landscape or portrait; team / field scene
- `works-01.webp`, `works-02.webp`, `works-03.webp` — verified project imagery
- `hero-hokkaido-nature-v1.png` — AI-generated photo-style Hokkaido nature visual for design review; replace with approved Rirary-owned photography before production unless explicitly approved.
- `home/wix-hero-local-communication.png` — local copy of the current/legacy Rirary Wix homepage hero image, approved by the user as an interim pre-deploy visual source.
- `regional/wix-cocreation-hiking.jpg` — local copy of the current/legacy Rirary Wix co-creation page image, approved by the user as an interim pre-deploy visual source.

Rules:
1. Prefer Rirary-owned original photos.
2. Do not use generic stock imagery as a hero unless explicitly approved.
3. Do not imply an unverified project, partner, result, or location.
4. Crop around people and activity rather than decorative scenery only.
