# Wix -> New Site Migration Notes

## Principles
- Keep `rirary.net` as the public domain.
- Build and verify the new site before DNS cutover.
- Inventory current indexable Wix URLs before launch.
- Map old URLs to new routes and configure permanent redirects where content moved.
- Preserve or deliberately replace useful titles/descriptions.
- Reuse current photos only when ownership and publication rights are clear and image quality is sufficient.
- Do not migrate Wix-specific pages that have no strategic value solely because they exist.

## Pre-launch checklist
- Redirect map complete
- Forms tested
- LINE/email links tested
- Analytics/search verification ready if used
- sitemap/robots checked
- OG images checked
- 404 page checked
- mobile QA complete
