# Contact real-device QA — v1.0

## Purpose

v1.0の問い合わせフォームは `mailto:` 方式のため、サイト側ではメール送信完了を検知できない。

公開前に、PCとスマートフォンの実機で「メールアプリが開くか」「代替導線が使えるか」を確認する。

## Test devices

最低限、次を確認する。

| Device | Browser | Result |
|---|---|---|
| PC | Chrome / Edge | 未確認 |
| iPhone | Safari / LINE内ブラウザ | 未確認 |
| Android | Chrome / LINE内ブラウザ | 可能なら確認 |

## Form test

1. `/contact` を開く。
2. 必須項目を入力する。
3. プライバシーポリシー同意にチェックする。
4. 「メールアプリを開く」を押す。
5. メール作成画面が開くことを確認する。
6. 宛先が `rirary2025@gmail.com` になっていることを確認する。
7. 件名が `Webサイトからのお問い合わせ（相談カテゴリ）` になっていることを確認する。
8. 本文に次が入っていることを確認する。
   - お名前
   - 会社・団体名
   - メールアドレス
   - 電話番号
   - ご相談内容
   - お問い合わせ内容

## Validation test

1. 必須項目を空にして送信しようとする。
2. ブラウザ標準の必須入力エラー、またはフォームのエラー表示が出ることを確認する。
3. プライバシーポリシー同意なしで送信できないことを確認する。

## Fallback link test

メールアプリが開かない場合でも、下部の代替導線を確認する。

| Link | Expected |
|---|---|
| LINE | 公式LINE URLを開く |
| EMAIL | `mailto:rirary2025@gmail.com` を開く |
| PHONE | `tel:08096170518` を開く |

## Acceptance

PCまたはスマートフォンの主要環境でメール作成画面が開き、代替導線も使えることを確認できれば、問い合わせ導線はv1.0公開可とする。
