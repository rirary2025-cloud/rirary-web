# Initial Kit Review v0.1 -> v0.2

## Review result
The initial kit is a good skeleton, but it is not yet strict enough to keep Codex from drifting during visual implementation.

## Keep
- Next.js App Router + TypeScript structure
- Server Components by default
- CSS variables as the design-token source of truth
- Business taxonomy: DIGITAL / CREATIVE / BUSINESS SUPPORT / COMMERCE
- REGIONAL PROJECT as an independent strategic section
- Primary CTA: 「まずは相談する」
- Mobile-first and accessibility requirements

## Improve in v0.2
1. Separate company positioning from individual services.
2. Treat current Wix content as source material, not the new information architecture.
3. Add explicit homepage narrative and section order.
4. Add global header/footer rules.
5. Add content hierarchy rules so section copy does not become verbose.
6. Add responsive type/spacing tokens and image-ratio rules.
7. Add a visual QA gate before declaring a page finished.
8. Add content models that are CMS-ready without introducing a CMS yet.
9. Add legal routes and migration notes so old URLs can later be redirected.
10. Ban ad-hoc inline styles for production sections except one-off calculated values.

## Design principle
The new website should feel like a regional business / project company, not an SNS agency landing page.
Digital and SNS capabilities are evidence of execution strength, but they are not the whole company identity.
