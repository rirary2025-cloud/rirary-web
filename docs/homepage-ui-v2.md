# Homepage UI/UX v2

## Purpose
This version moves the homepage from wireframe-level structure to a visual system that can guide production implementation.

## Visual thesis
**Warm editorial × Hokkaido × field execution × orange signal**

The page should feel human, local, and operational. It must not resemble a generic SaaS landing page or a social-media agency template.

## Brand expression
- Base: off-white / warm sand / ink black.
- Accent: Rirary orange, used as a signal rather than a full-page fill.
- One full orange CTA block near the bottom establishes a memorable brand finish.
- One dark regional-project block creates strategic contrast.
- Photography will eventually replace abstract visual placeholders; the layout must not depend on stock imagery.

## Header
Desktop:
- Sticky warm translucent header.
- Rirary wordmark at left.
- BUSINESS / WORKS / REGIONAL PROJECT / ABOUT / NEWS centered-right.
- Orange consultation CTA at far right.

Mobile:
- Wordmark left.
- Optional compact consultation pill from 640px.
- Circular menu trigger right.
- Menu interaction remains implementation work; no fake drawer behavior in static prototype.

## Hero
Editorial two-column composition.

Left:
- eyebrow
- large Japanese declaration
- short supporting paragraph
- two actions

Right:
- abstract field/project placeholder using circles, grid lines, and an index number.
- later replace with approved Rirary project photography without changing dimensions.

Bottom ticker:
`LOCAL × DIGITAL × CREATIVE × BUSINESS`

This gives the first screen energy without relying on video or animation.

## Business cards
- 2×2 asymmetric desktop arrangement.
- Cards remain quiet white against paper background.
- Hover uses a subtle lift and orange-border signal.
- Second and third cards are vertically offset only on tablet/desktop.

## Approach
Use numbered editorial rows, not feature cards.
The number, principle, and explanation form a three-column rhythm on desktop and stack on mobile.

## Works
Three-card editorial preview.
Until approved images exist, each media frame uses a neutral abstract placeholder and a large translucent index.
The middle card drops lower on desktop to avoid a catalogue-grid feel.

## Regional Project
Full-width dark section.
- Copy left.
- tall media field right.
- orange dot + orbital geometry are temporary visual language.
- once real project photography is selected, retain dark frame and copy layout.

## News
Compact horizontal rows.
Mobile prioritizes date + title; category appears from 640px upward.

## Final CTA
Full Rirary orange section with white/outlined actions.
This is the strongest orange area on the entire homepage.

## Footer
Dark editorial footer.
Keep company statement, key navigation, privacy, and copyright only.
Avoid dense corporate-link matrices.

## Typography
Current code uses system Japanese fonts for portability.
Before launch, select a production-safe Japanese type stack or licensed web font and test:
- Japanese line breaks
- numeric appearance
- Latin labels
- mobile loading performance

## Photography rules
Approved priority:
1. Rirary members in real activity
2. Hokkaido / municipality / regional project scenes
3. client work and local businesses
4. landscape only when it supports a story

Never use generic stock business-handshake imagery.
