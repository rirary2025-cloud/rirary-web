# Brand / photo asset plan — v0.6

## Objective
Move the site from placeholder UI to an asset-ready production structure without inventing an official brand mark or project imagery.

## Current Wix findings
The current Wix site contains multiple Wix-hosted images, including a large image labelled `Untitled design.png`, SNS-related graphics, and an image used on the co-creation page. The current content also contains generic/stock-like visual material. These should not automatically become the new website's primary brand imagery.

## Production priority
1. Official Rirary Japanese-honeybee logo / symbol
2. Rirary-owned real field photos
3. Verified project / work photos
4. Team / company photos
5. OGP image

## Hero visual direction
Use real activity rather than a generic Hokkaido landscape wherever possible.
Recommended subjects:
- talking with local business / municipality members
- event / regional project operations
- creating, filming, planning, or working in the field
- a wide Hokkaido context visible as secondary information

## Image treatment
- warm natural color
- minimal heavy filters
- strong crop, documentary feeling
- radius consistent with design tokens
- use orange only as an accent overlay / marker

## Fallback behavior
Until production assets exist, the UI uses an abstract editorial field graphic. This is intentional and must not be mistaken for final photography.
