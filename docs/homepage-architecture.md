# Homepage Architecture v0.2

## Goal
Within 10 seconds, a visitor should understand:
1. Rirary is a Hokkaido-based company solving regional business/community problems.
2. It works across digital, creative, business support, commerce, and regional projects.
3. It can move from idea to execution.
4. There is a clear way to start a consultation.

## Narrative order

### 01 HERO
Eyebrow: `RIRARY / HOKKAIDO`
Headline: `北海道の地域課題を、新しい発想で解決する会社。`
Supporting copy: short explanation of combining business, digital, creative, and local collaboration.
CTA: `まずは相談する`
Secondary: `事業を見る`
Visual: authentic Hokkaido / people / work / project photograph. Avoid generic office stock.

### 02 INTRO / WHAT WE DO
Purpose: explain Rirary in one paragraph, not a service list.
Suggested heading: `地域の「困った」を、事業に変える。`
Explain that Rirary identifies the actual bottleneck and combines the necessary methods instead of selling a predetermined tool.

### 03 BUSINESS
Four business pillars:
- DIGITAL / デジタル支援
- CREATIVE / クリエイティブ
- BUSINESS SUPPORT / 事業支援
- COMMERCE / コマース
- CACAO IMPORT / カカオ加工品の輸入事業
Each card: one outcome-oriented sentence + detail link.

### 04 APPROACH
Purpose: preserve the useful philosophy from the current site.
Keywords:
- 地域ごとに市場は違う
- アナログ × デジタル
- 点ではなく線で設計する
- 実行まで伴走する
Use a diagram, not a long essay.

### 05 WORKS
Show 3-6 selected projects/cases.
Every card contains category, title, client/region when publishable, short result/role, image.
Link to `/works`.

### 06 REGIONAL PROJECT
Visually distinct full-width section.
Purpose: make regional activation a strategic pillar rather than burying it among services.
Explain projects created with municipalities, local companies, organizations, and residents.
Link to `/regional-project`.

### 07 ABOUT / CO-CREATION
Suggested heading: `競争だけではなく、共創で地域を前へ。`
Shorten the current philosophy into a readable statement.
Link to `/about`.

### 08 NEWS
Latest 3 entries only. Do not let news dominate the page.

### 09 FINAL CTA
Heading: `まずは、話すところから。`
Support: problem does not need to be fully defined before contacting Rirary.
Actions: form / LINE / email.

## Mobile behavior
- Hero headline 2-4 lines, never tiny to force desktop line breaks.
- Business cards stack 1-column.
- Works use horizontal snap only if usability remains obvious; otherwise stack.
- CTA is always reachable without relying on hover.
- Header switches to compact menu below tablet width.
